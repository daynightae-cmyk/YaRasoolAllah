# Archived capability prototypes

These files were removed from active product code during the P0 trust closure on 2026-09-23.

- `BookReader.tsx` rendered invented placeholder prose while presenting controls for real page progress.
- `DownloadManager.tsx` displayed simulated random progress rather than transport progress.
- `downloadService.ts` marked a simulated timer complete and then opened an external URL.

They remain in Git as implementation references only. They must not be restored until the library has item-level availability, source, edition, file, and rights records plus a real reader/download pipeline.
