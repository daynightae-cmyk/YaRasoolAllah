# Hadith and grading provenance
Sunnah.com official developers page says its API covers **a portion** of its manually checked data and requires a key requested through its official GitHub repo. Docs: https://sunnah.com/developers ; https://sunnah.stoplight.io/docs/api/ ; implementation/spec: https://github.com/sunnah-com/api . Endpoint paths and payload require key/doc validation; **NOT VERIFIED** here. No wholesale reproduction/scraping: see site's own terms.

Dorar officially documents `GET https://dorar.net/dorar_api.json?skey=<encoded query>`; JSONP sample uses `callback=?`, results `ahadith[].th` HTML. Use backend GET and safe HTML parser/sanitizer; query functionality, CORS, pagination and rights need a live probe and approval. Treat grade/assessor as separately parsed fields only if explicitly present; never derive from color or search ranking. https://dorar.net/article/389/خدمة-واجهة-الموسوعة-الحديثية-API .

HadeethEnc has multilingual hadith, downloadable spreadsheets and a Developers API link. The docs returned HTTP 429 in our browser. It is a promising per-record translation/grade source, **endpoint/schema NOT VERIFIED**. https://hadeethenc.com/ar .

HF `quranlab/hadith` dataset card advertises an Arabic nine-books spine plus HadeethEnc translations, with row fields `hadith_key,hadeethenc_id,language,title,text,grade,grader,grade_source,attribution_text,explanation,source,license`. This is a **derivative**; verify each upstream record and terms before using in production. https://huggingface.co/datasets/quranlab/hadith . Third-party scraped `AhmedBaset/hadith-json` is research candidate only, not authoritative. https://github.com/AhmedBaset/hadith-json .

Join key: `provider:collection:book:hadithNumber:edition`, plus `sourceUrl` and external numbering variants. Grade is a claim with `gradeText,assessor,assessorSourceUrl`, **never** a substitute for `editorialReviewStatus`. For Bukhari, Muslim, Abu Dawud, Tirmidhi, Nasa'i, Ibn Majah, Muwatta, Riyad as-Salihin, Forty Nawawi and Shama'il, record actual provider coverage rather than infer completeness. Current UI: `services/hadith.ts`, `pages/HadithPage.tsx`; preserve four development samples' labels.
