# Quran audio
MP3Quran official docs https://www.mp3quran.net/de/api : `GET https://mp3quran.net/api/v3/reciters?language=eng` returns `reciters[]` with `id,name,moshaf[]`; each moshaf has `id,name,server,surah_total,surah_list`. Server URL is a base path; only form `server + surah.toString().padStart(3,'0') + '.mp3'` after confirming the specific item exists via HEAD/GET and stream/use rights. Official timing `GET https://mp3quran.net/api/v3/ayat_timing?surah=2&read=5` returns array of `ayah,start_time,end_time`; official sample includes `ayah:0` opening segment; do not assume 0 means Quran ayah zero, validate units (sample appears milliseconds), map to track's read ID. `/api/v3/ayat_timing/reads` lists timed reads. Distinguish reciter ID, moshaf ID, read ID.

Quran Foundation v4: `/content/api/v4/resources/recitations` (ayah-by-ayah IDs) and `/resources/chapter_reciters` (different IDs), `/chapter_recitations/{reciter_id}/{chapter_number}` and timestamp lookup. Never interchange IDs. https://api-docs.quran.foundation/docs/content_apis_versioned/4.0.0/recitations/ ; https://api-docs.quran.foundation/docs/content_apis_versioned/4.0.0/chapter-reciters/ ; https://api-docs.quran.foundation/docs/content_apis_versioned/4.0.0/chapter-reciter-audio-file/ .
