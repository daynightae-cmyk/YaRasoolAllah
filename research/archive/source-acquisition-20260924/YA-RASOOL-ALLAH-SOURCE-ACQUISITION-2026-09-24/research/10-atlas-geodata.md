# Atlas and terrain
MapLibre GL JS GeoJSON source `map.addSource('modern-places',{type:'geojson',data:...})` renders reviewed modern geography; optional raster-dem `type:'raster-dem'` for terrain requires a tile provider/terms and performance check. Docs https://maplibre.org/maplibre-gl-js/docs/API/classes/GeoJSONSource/ ; https://maplibre.org/maplibre-gl-js/docs/API/classes/RasterDEMTileSource/ . Natural Earth provides downloadable modern cultural/physical reference datasets https://www.naturalearthdata.com/downloads/ . GeoNames elevation/timezone APIs for point data https://www.geonames.org/export/web-services.html ; NASA Earthdata SRTM catalog https://www.earthdata.nasa.gov/data/instruments/srtm .

OpenHistoricalMap offers historical feature data, but every early-Islamic feature still requires an item-level source review, confidence, date interval. OSM's history API describes changes to **modern mapping data**, not the seventh-century landscape. https://wiki.openstreetmap.org/wiki/OpenHistoricalMap/Reuse . The current `services/atlas.ts` intentionally uses layout coordinates tagged `schematic`. Keep schematic narrative layer separate from real modern coordinates and from researched historical hypotheses. Do not transform `layout.x/y` into lat/lon or draw precise battle routes.

GeoJSON layers: modern place markers use `geometry.coordinates:[longitude,latitude]`; reviewed historical claims use a separate FeatureCollection carrying `sourceReferenceIds,confidence,geometryStatus`; unknown geometry stays off-map with a text list. Map tiles, SRTM downloads, MapTiler plans/CORS/rates are **NOT VERIFIED** for this project.
